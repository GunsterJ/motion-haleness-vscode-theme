# Motion Haleness

A modern, high-contrast dark theme for **Visual Studio Code**.

## Features

- Optimized for AI agents: *Claude Code*, Codex and Kilo Code
- High-contrast chat and diff colors
- [Install from the marketplace](https://marketplace.visualstudio.com)

> Balanced contrast, vibrant accents, readable comments.

```ts
const theme = "motion-haleness";
```
